\section{Introduction}
Through observation, it was identified that the Ziva physics solver occasionally fails to properly resolve collisions for the complex attachment skin and muscle system during high-velocity impacts (e.g., the finger clap effect). To address this, we have implemented a custom, bulletproof collision response mechanism that operates independently of the Ziva solver, drawing inspiration from our robust target shrink-wrap registration algorithm.

\section{Methodology}
The custom collision response uses a direct geometry-projection approach:
\begin{enumerate}
    \item \textbf{Prior Knowledge:} We utilize a predefined set of vulnerable skin vertices (e.g., \texttt{ImpactCenter (15163)} and surrounding ripples) that are known to intersect with the hand geometry during the clap simulation.
    \item \textbf{Transition Timing:} The hand transition speed has been modified to a 15-frame duration from the rest pose to the target impact pose. This provides the soft-tissue simulation adequate time to respond naturally while preventing sudden, unstable spikes in physical forces.
    \item \textbf{SDF-like Distance Checking:} During the simulation, we calculate the exact distance between the tracked skin vertices and the closest point on the hand mesh (using \texttt{MFnMesh.getClosestPoint}).
    \item \textbf{Displacement Enforcement:} If a skin vertex falls within the collision threshold (1.5 cm) of the hand mesh, it is physically pushed outward along the face normal of the nearest hand polygon. This guarantees zero penetration.
\end{enumerate}

\section{UI Integration}
This system has been integrated into the piano-style interactive animation interface (\texttt{h99-UI-mayascipt-V1.py}):
\begin{itemize}
    \item \textbf{Enable Finger Clap Effect (Collision):} A checkbox that registers a \texttt{scriptJob} linked to \texttt{timeChanged}. When enabled, the collision response is enforced at every frame evaluation.
    \item \textbf{Run Finger Clap Test:} A dedicated button to execute the 6-clap passive dynamics test.
    \item \textbf{Auto-Playblast:} If the \texttt{auto\_playblast} setting is enabled, the test will automatically render a viewport playblast upon completion, saving the output video with a unique datetime stamp for analytical review.
\end{itemize}
